# Liburan Seru — Versi Statis

Website statis (satu file `index.html`) **Liburan Seru** untuk membuat itinerary, mencatat jastip, dan menyimpan tempat wisata, tempat makan, dan hotel — untuk semua destinasi.

Logo: logo lama dari aplikasi Flutter Liburan Seru (16 Nov 2026) — globe teal tersenyum di latar oranye + tas belanja & koper, dan logo lengkap "Liburan Seru — JASTIP • TRAVEL DUNIA". File aslinya (`logo-icon.webp` dan `logo-full.webp`, byte-for-byte dari repo `liburan-seru-flutter`) disimpan di folder ini, dan karena konektor GitHub menolak upload file biner, logo itu di-embed ke `index.html` sebagai data URI (byte yang sama persis) supaya tampil di GitHub Pages. Nama brand "Liburan Seru" sama di mode Bahasa Indonesia dan Inggris.

Buka lewat GitHub Pages: https://danryu655-ship-it.github.io/itinerary-jastip-wisata/

## Fitur

- **Rencana & Itinerary** — buat trip (nama, kota, tanggal, budget, jumlah orang — bisa diubah lewat tombol Ubah di kartu trip), form "Buat Trip Baru" otomatis tersembunyi bila sudah ada trip — dibuka lewat tombol "+ Perjalanan baru" di atas tab (atau tombol "Buat perjalanan pertama" pada kartu kosong saat belum ada trip), dan tombol Batal menyembunyikannya lagi; bila belum ada trip sama sekali form langsung tampil), itinerary harian otomatis (penomoran Hari 1, 2, 3… dihitung dari komponen tanggal lokal, jadi tidak bergeser zona waktu), tambah item (jam mulai + durasi dengan jam selesai otomatis, kategori wisata/makan/hotel/transport/belanja, biaya dalam mata uang apa pun dengan konversi IDR otomatis dari kurs tersimpan, **Berangkat menggunakan**: Jalan kaki / Motor / Mobil / Kereta / Pesawat). Setiap trip punya card **🏨 Hari Hotel** tepat sebelum Hari 1 — tanggalnya otomatis sehari sebelum tanggal mulai trip — berisi hanya Nama Hotel, Alamat, dan tombol Simpan; alamat hotel yang disimpan menjadi titik berangkat bawaan aktivitas pertama (hari lain yang belum punya Lokasi Hotel sendiri juga memakainya). Setiap hari punya field **Lokasi Hotel** di atas daftar aktivitas — lokasi hotel hari itu menjadi titik berangkat bawaan aktivitas pertama hari itu (bawaan "Hotel" bila belum diisi) dan bisa menimpa alamat hotel trip. **Jarak Perjalanan & waktu tempuh** ada di setiap aktivitas, dari titik berangkatnya (hotel untuk aktivitas pertama, aktivitas sebelumnya untuk berikutnya), bisa dihitung otomatis dari peta (tombol "🗺️ Hitung otomatis dari peta", juga tombol 🗺️ di tiap item) via Nominatim + OSRM — kereta/pesawat memakai perkiraan garis lurus dan dilabeli jelas; kalau tempat tidak ketemu di peta, isi manual (tidak dikarang). Ringkasan per hari dan total trip: total biaya (IDR), total jarak, total waktu tempuh, total durasi kegiatan. Biaya aktivitas & perjalanan diisi **per orang** dan semua total otomatis dikali jumlah orang (mis. ¥730/orang × 4 orang = ¥2.920, dikonversi ke IDR pakai kurs tersimpan — dengan kurs default JPY 108 menjadi Rp315.360; bila kurs diperbarui online, total ikut berubah) — mengubah jumlah orang langsung mengubah semua total; bila 1 orang, tampilan tetap seperti biasa. Centang selesai, bar budget, salin itinerary sebagai teks (termasuk lokasi hotel per hari dan perjalanan dari titik berangkat), dan tombol **🖨️ Cetak / PDF** di tiap trip — membuka pratinjau lembar cetak rapi (card Hari Hotel tampil di atas itinerary Hari 1) dengan tombol utama **⬇️ Unduh PDF** yang membuat file PDF A4 betulan di perangkat (tanpa library tambahan, hanya API browser bawaan: lembar cetak dirender lewat SVG foreignObject → canvas → PDF A4 multi-halaman yang dirakit sendiri) lengkap dengan status "Menyiapkan PDF…" / "✓ PDF terunduh" dan pesan jelas bila gagal, plus tombol cadangan **🖨️ Cetak via browser** (`window.print()`, pilih "Save as PDF" di dialog printer). Lembar cetak/PDF kini per hari: halaman pertama berisi judul + blok info + card Hari Hotel, tiap hari dimulai di halaman baru dengan pita header toska dan kotak ringkasannya tepat di bawah header, ringkasan total trip di halaman sendiri di akhir, dan PDF unduhan bernomor halaman ("Halaman X dari Y"). Tombol **📋 Salin Itinerary** menyalin jadwal sebagai teks — berguna untuk ditempel ke WhatsApp, catatan, atau email, seperti dijelaskan di bawah tombol — dengan jalur cadangan berlapis (Clipboard API, lalu salin manual lewat panel berisi teks lengkap bila otomatis gagal) dan selalu memberi umpan balik terlihat, tidak pernah gagal diam-diam. Lembar Cetak/PDF didesain ulang agar mudah dibaca orang awam: judul trip besar + blok info berlabel (Destinasi, Tanggal, Jumlah orang, Budget), card Hari Hotel berlabel Nama Hotel/Alamat, tiap hari jadi tabel (Jam | Kegiatan | Tempat | Biaya kegiatan | Perjalanan) dengan kalimat perjalanan sehari-hari — mis. "Naik kereta, perjalanan 14 menit, dari Hotel, berangkat 07:50, jarak 2,9 km, ongkos ¥210/orang" (waktu tempuh tepat di sebelah moda) — dan kotak ringkasan berisi Total biaya, Total jarak, Total lama perjalanan, dan Total lama kegiatan, baik per hari maupun total trip; kontras tinggi, spasi lega, tetap terbaca saat dicetak hitam-putih. Di tabel PDF, kolom Perjalanan diganti baris perjalanan penuh antar aktivitas ("🧭 Perjalanan: Hotel → Fushimi Inari Taisha • Naik kereta • Berangkat 07:50 • Perjalanan 14 menit • Jarak 2,9 km • Ongkos ..."), dan pita yang sama tampil di antara aktivitas di layar; baris perjalanan hanya muncul bila aktivitas tujuan punya data perjalanan. Tiap seksi hari punya tombol **"+ Tambah aktivitas"** sendiri (form tambah/ubah terbuka di dalam card hari itu dengan tanggal hari itu sudah terisi, dan aktivitas tersimpan muncul di hari yang sama); tombol **Ubah** di tiap item membuka form yang sudah terisi semua isian tersimpan (tanggal, jam, durasi, biaya + mata uang, kategori, lokasi, moda, titik berangkat, jarak, waktu tempuh, catatan), dan berpindah item tidak membawa isian lama (tidak stale). Editor **Lokasi Hotel** per hari terisi alamat dari card Hari Hotel bila belum diisi sendiri. Seksi **🧭 Perjalanan menuju aktivitas ini** di form tambah/ubah punya **Perkiraan Biaya** perjalanan + mata uangnya (default mengikuti mata uang biaya aktivitas; ikut dihitung ke total biaya per hari & total trip, dikonversi ke IDR) dan **Jam keberangkatan** (opsional, boleh kosong); keduanya tersimpan per aktivitas, terprefill saat form Ubah dibuka, dan tampil di kartu aktivitas, salinan teks, dan lembar Cetak/PDF. Tombol **⬇️ Ekspor Trip** di kartu tiap trip mengunduh trip lengkap sebagai file JSON (`Liburan Seru - {judul trip}.json`, berpenanda `{"app":"Liburan Seru","formatVersion":1}`) berisi data trip, semua aktivitas, card Hari Hotel, dan Lokasi Hotel per hari; tombol **⬆️ Impor Trip** di tab Perjalananku membaca file yang sama lewat pemilih file (trip bisa pindah dua arah) — file yang bukan data Liburan Seru ditolak dengan pesan jelas, dan bila trip dengan nama + tanggal yang sama sudah ada, pengguna memilih **Timpa trip lama** atau **Simpan sebagai trip baru** (tidak pernah menimpa diam-diam); trip yang diimpor tersimpan di localStorage browser.
- **Jastip** — catat titipan (yang nitip, barang, toko, harga dalam 15+ mata uang dengan estimasi IDR otomatis dari kurs tersimpan, fee, prioritas), status perjalanan Dicari → Dibeli → Dibawa → Selesai plus status bayar Belum Bayar / DP / Lunas (ketuk chip untuk ganti), total + total belum lunas.
- **Kurs & Konverter** — 17 mata uang ke IDR (kurs default perkiraan Nov 2026 dari aplikasi lama, bisa diubah manual, tersimpan di browser, dan diperbarui online via open.er-api.com dengan fallback manual kalau offline).
- **Jelajah & Tempatku** — katalog 19 destinasi: Osaka, Kyoto, Tokyo, Bali, Yogyakarta, Seoul, Bangkok, Singapore, Kuala Lumpur, Labuan Bajo, London, Paris, Roma, Madrid, Swiss Alps, Dubai, Istanbul, New York, Sydney, lengkap dengan panduan wisata/kuliner/area hotel/ide jastip, city pass, contoh itinerary 3–4 hari, dan tombol "Buat rencana". Pencarian kota di luar katalog menampilkan pesan jujur bahwa datanya belum ada — tidak ada link booking atau harga palsu. Di bawah katalog ada seksi **Tempatku** — simpan tempat (nama, kota, kategori, rating, link Google Maps), filter per kategori.
- **Navbar floating bawah** — pill gelap, tombol aktif teal, bisa digeser menyamping di HP.
- **Asisten AI floating** — tombol di kanan bawah di atas navbar. Chatbot **rule-based client-side saja** (tanpa server / API key). Bisa memberi contoh itinerary, ide wisata/kuliner/hotel/jastip untuk kota katalog, dan membaca data trip/jastip/tempat yang tersimpan di browser kamu.

## Data

Semua data tersimpan di browser kamu (localStorage, prefix `ijw_`). Tidak ada server, tidak ada akun, tidak ada data yang dikirim ke mana pun.

## Batasan yang jujur

- Harga yang tampil adalah **perkiraan, cek ulang** sebelum berangkat.
- Chatbot versi statis ini rule-based, **tidak bisa booking dan tidak bisa mengubah data**.
- Versi fullstack asli di Muse (dengan penyimpanan server dan AI sungguhan) tidak bisa diekspor — ini adalah versi statis yang dibuat ulang untuk GitHub Pages.
